Ontology for the FAIRified municipal results of the Dutch information security standards measurement

Terms that extend the W3C Evaluation and Report Language (EARL), PROV-O and SKOS to describe the per-host results of the half-yearly measurement of mandatory internet security standards by Forum Standaardisatie: the security tests and the standards they check, the outcome codes of the measurement, and the explicit, rule-based attribution of internet hosts to Dutch municipalities.

HSTS (HSTS@nl)

https://w3id.org/FAIR-course-UT/2026/group33/ont#hsts

Checks for HTTP Strict Transport Security (HSTS), which makes a browser require that a website keeps using HTTPS after the first contact over HTTPS, so that a third party cannot redirect the browser to a fake website.

error (fout@nl)

https://w3id.org/FAIR-course-UT/2026/group33/ont#error

The test could not be completed due to an error (either on the tool's or the server's under test side). Other tests that depend on this one will therefore not be able to run.

Door technische omstandigheden is de server niet bereikbaar met het geconfigureerde IPv4- en/of IPv6-adres.
